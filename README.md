# AI-Based Educational Platform

## About the Project
An AI-powered platform designed to make learning easier and smarter for students.

## Problem Statement
Students often struggle to understand difficult concepts and find suitable learning resources.

## Solution
Our project uses Artificial Intelligence to support students and improve their learning experience.

## Technologies Used
- Python
- Streamlit
- Artificial Intelligence

## How to Run
1. Install Python.
2. Install dependencies using pip.
3. Run the application using:

python -m streamlit run app.py

## Purpose
This project is developed for educational and hackathon purposes.
